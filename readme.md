# Fã clube dos Minions

## Sobre o projeto
Este projeto foi desenvolvido para uma avaliação prática da unidade curricular Programação de Aplicativos.

O site apresenta informações sobre os Minions, seus personagens, curiosidades e um quiz interativo para os visitantes descobrirem seu nível de fã.

## Tecnologias utilizadas
- HTML5
- CSS
- JavaScript

## Funcionalidades
- Apresentação dos personagens.
- Lista de curiosidades.
- Formulário interativo.
- Validação dos campos.
- Mensagens de erro e sucesso.
- Layout adaptável para celulares.

## Como funciona o quiz?
O visitante informa seu nome, quantos filmes assistiu e quantas bananas comeria em um dia.

A pontuação é calculada da seguinte forma:

- Cada filme vale 10 pontos.
- Cada banana vale 2 pontos.

O resultado classifica o visitante em três níveis:
- Fã iniciante.
- Super fã.
- Fã número 1 dos Minions.
